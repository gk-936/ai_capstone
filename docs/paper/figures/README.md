## Notes / caveats carried over from the text

- `fig3`: qwen2.5-vl-7b has no reported V4a value in the source material — left
  blank rather than invented, and labeled "not reported" on the chart.
- `fig4`: the V4a `relevant`-occlusion condition is contaminated by the gray
  occluder itself tripping the `names_confound` matcher (documented in §6.2);
  the grounding claim rests on the V4b-internal contrast only. The chart
  carries this caveat as a footnote so it isn't misread standalone.
- `fig5`: supervised target adaptation has no CI reported in the source
  material (open diamond marker, no whiskers) — don't add error bars to it
  without a real bootstrap re-run.

Both `.png` (raster, for quick preview / Word) and `.pdf` (vector, for the
LaTeX build) are written for every new figure.
